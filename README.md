# 网页与知网 PDF 入 ima

这是一个独立的 Microsoft Edge 扩展，可以把网页转成 PDF 或以链接保存到所选腾讯 ima 知识库及文件夹。知网单篇文章详情页还可以上传你有权下载的原始 PDF。

本项目由社区独立开发，**不是**中国知网、腾讯 ima 或 Zotero 的官方产品。

## 安装

### 从 GitHub Release 下载（推荐）

1. 在本仓库的 **Releases** 页面下载 `cnki-ima-0.4.0-edge.zip`，解压到一个以后不会随意移动的文件夹。
2. 在 Edge 地址栏输入 `edge://extensions/`，打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择解压后**直接包含 `manifest.json`** 的文件夹。
4. 打开扩展的“设置”，从 [腾讯 ima 官方接口页面](https://ima.qq.com/agent-interface)获取你自己的 Client ID 和 API Key，填入并点击“保存并测试连接”。不要把这些凭证发给别人或提交到 GitHub。

GitHub 的“Code → Download ZIP”也可以安装：解压后选择其中包含 `manifest.json` 的项目文件夹。GitHub 下载链接本身不能让 Edge 一键安装；商店式安装需要另行上架 Microsoft Edge 扩展商店。

## 使用

1. 在 Edge 打开要保存的网页。上传论文 PDF 时，请打开一篇你有权限下载完整 PDF 的**知网单篇文章详情页**。
2. 点击扩展图标，选择本次要使用的 ima 知识库和文件夹。保存到根目录也需要选中“根目录”。
3. 点击“整页转 PDF”“保存网页链接”，或在有下载入口的知网详情页点“下载知网原始 PDF”。开始后可以关闭弹窗，保留当前标签页。重新打开弹窗可以查看任务进度和结果。

Edge 扩展管理页在空闲时可能显示服务工作进程“不活动”。打开扩展时，Edge 会唤醒后台。同一次 Edge 会话中，如果后台在上传中重启，重新打开弹窗会提示任务中断。请先核对目标知识库，再自行重试。知网要求安全验证时，请在知网页面完成验证，然后回到扩展重试。

已有同名 PDF 时扩展会停止，避免重复上传。若知网返回登录页、验证码页、试读内容或其他非 PDF 响应，扩展会报错，不会上传该响应。

## 支持范围与限制

- “整页转 PDF”使用 Edge 的打印引擎，把当前 HTTP(S) 网页的可打印内容自动分页，包含屏幕下方的文字和图片。网站的打印样式会影响排版。对滚动后才由网站加载的内容，请先滚动到需要保存的位置，等待内容出现再转换。
- “网页 PDF 排版”默认使用“自动适宽”，按网页宽度调整纸张和缩放，适合门户首页、宽图和多栏网页。适宽版文件名带有“网页·适宽”。
- “正文排版（适合文章）”使用 [Mozilla Readability 0.6.0](https://github.com/mozilla/readability/releases/tag/0.6.0) 提取标题和正文，然后由 Edge 以统一的 A4 版式生成 PDF。导航、侧栏、交互图表等内容可能不在正文里。保存门户首页或档案页面的完整布局时请用“自动适宽”。正文版文件名带有“网页·正文”。
- 这两种网页 PDF 的页眉都带有网站名称、来源网址、作者或发言人、公布时间。网页没有标注站名时显示域名，缺少作者或公布时间时显示“未标注”。
- “保存网页链接”将当前 HTTP(S) 地址交给 ima。需要登录才能访问的链接可能无法由 ima 解析。
- “下载知网原始 PDF”支持详情页上能识别到直接指向 `*.cnki.net` HTTPS 地址的 PDF 下载链接。需要 JavaScript 特殊跳转、额外购买或验证码的文章可能失败。
- PDF 必须不超过 ima 接口的 200 MB 上限。扩展会检查 PDF 文件头和结束标记；这不能证明所有未标记的试读文件都是完整论文，重要文章请在 ima 中核对页数。
- 需要用户自己的知网下载权限和 ima API 凭证。本仓库不提供文章、下载权限或 API Key。
- 扩展在浏览器内存中获取 PDF 后上传到 ima 分配的腾讯 COS 目标，不在系统“下载”目录另存副本。

## 隐私与权限

扩展所请求的主机范围是知网、`ima.qq.com` 和腾讯 COS。点击扩展时读取当前标签页地址，选择“保存网页链接”后才把地址提交给 ima。`debugger` 权限用于生成网页 PDF。整页转换临时连接当前标签页，正文排版在本机提取正文，再临时连接独立的打印标签页。转换结束或失败后即断开，正文打印标签页会随之关闭。此时 Edge 可能显示调试提示。`cookies` 与 `declarativeNetRequest` 权限用于在 PDF 请求中携带知网页面来源以及必要的分区 Cookie，相应请求头规则在请求结束后移除。ima Client ID 与 API Key 保存在本机 Edge 扩展存储中，不包含在仓库或下载包里。

## 开发

Readability 已随源码打包，本项目无需另行安装 npm 依赖。使用 Node.js 运行：

```text
npm test
npm run check
```

自动化测试覆盖链接识别、PDF 校验、请求头规则、ima API 编排及上传处理。知网网站和登录状态会变化，自动化测试不能代替实际文章的端到端验收。
